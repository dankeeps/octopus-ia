# Não é para você se

## A ideia

Diz para quem o vídeo não serve. Filtra e aumenta o interesse de quem se encaixa.

## Quando usar

Público muito amplo ou com muito curioso.

## Exemplo

> Se você quer fórmula para ficar rico em trinta dias, nem clica. Esse vídeo é para quem tem um negócio que já vende.
