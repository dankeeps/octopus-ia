# Lista do Sucesso — Template 23

## A ideia

Esse é um formato de copy perfeito para gerar conexão e aumentar a crença de que é possível conseguir o resultado desejado. Tudo que você precisa fazer é listar todas as ações que você fez para ter algum resultado, e explicar a lógica por trás dessas ações.

## Estrutura

- Tudo que eu fiz para ter tal resultado
- Mostrar tudo que vc fez
