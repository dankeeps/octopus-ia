# Palavras-chave Spy

As palavras para pesquisar na Biblioteca de Anúncios da Meta quando o Spy roda.

**Como combinar:** palavra **do próprio nicho** + palavra **do mercado** (ex.: *Blue pill* +
*trick*). Ou pesquise o **nome chiclete** da própria oferta (ex.: *Pink salt*).

As palavras do mercado valem para qualquer nicho. Nicho novo entra como uma seção nova,
na mesma tabela de três colunas. O relatório de cada Spy guarda quais palavras foram
usadas (`palavras_buscadas`).
