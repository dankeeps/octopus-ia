# Estruturas de VSL

> [!info] Para que serve
> Uma estrutura é a sequência de blocos de uma VSL, com nome. Ninguém é obrigado a encaixar uma VSL aqui: ao estudar uma VSL, o agente monta a estrutura **dela**, do jeito que ela é. Depois compara com esta pasta. Se bater com uma estrutura, usa o nome. Se não bater, a estrutura é "própria" e pode virar uma nota nova aqui.
