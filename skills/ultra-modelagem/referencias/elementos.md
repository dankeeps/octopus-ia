# "Elementos persuasivos" = o controle de mercado

Quando o usuário fala em elementos persuasivos, ele está falando do que o controle de mercado da oferta já guarda. Não é uma lista para preencher de novo: é onde buscar.

| O usuário chama de | No controle de mercado está em |
|---|---|
| Dores | Dores |
| Desejos | Desejos |
| Promessa | Promessas |
| Soluções comuns | Soluções comuns |
| Mecanismo | Mecanismo |
| Provas, Autoridade | Provas |
| Objeções, Realidade, História, Future pacing, Itens conhecidos pela audiência | no texto dos anúncios do controle de mercado: leia os validados inteiros (`ler_anuncio_do_controle`) e tire de lá |

O que não estiver em nenhum dos dois lugares não entra no anúncio.
